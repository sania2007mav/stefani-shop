# Stefani — интернет-магазин женской одежды

Дипломный проект: витрина бренда **Stefani** (каталог, корзина → WhatsApp, админ-панель на Firebase).

## Онлайн

- Выбор дизайна: страница репозитория на GitHub Pages (после публикации)
- Firebase (мягкий дизайн): https://stefani-shop-7k3m.web.app/

## Варианты дизайна

| Папка | Стиль |
|---|---|
| `website/` | мягкий / розовый + админка |
| `website-strict/` | строгий editorial |
| `website-minimal/` | minimal / VELORA-like |

## Локально

```bash
cd website
python -m http.server 8080
```

Админка: `/admin.html` (вход через Firebase Authentication).
